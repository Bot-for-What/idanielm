About Me

Based in Guwahati, originally from Shillong

It all started with a love for making things work better — and once that door opened, there was no closing it.

What began as basic Excel quickly grew into something else entirely. A shared network downtime tracker used across multiple units. A patient journey turnaround sheet pulling live data from different departments. Print job counters, vendor ticket trackers, radiology and lab machine usage reports — all built because someone had a manual process and I couldn't help but wonder if there was a better way. Then a senior colleague showed me Active Directory Server Policies, and something clicked harder. Scripts, Group Policies, print server management, login trackers — each one a new puzzle, each solution a reason to go deeper.

At my current company, I fell headfirst into Docker and the world of open source software. What started as a Google Form with a Telegram integration became a self-hosted ecosystem of 19 actively maintained applications — DNS management, internal domain routing, asset tracking, a ticketing system, media signage across the building, a reception call log, document automation across departments.

Nobody told me to do any of it. But noticing the pain points of the people around you — and quietly making them disappear — that's a satisfaction of a different level.

Technitium DNS · Caddy · Docker

Naming Convention vs. Remembering IP Addresses

// what was broken

Accessing any self-hosted app meant remembering a raw IP and port — 192.168.x.x:8080 style addresses that nobody could keep straight, let alone share with non-technical colleagues. Every new app added another combination to memorise.

// what was built

Technitium DNS now resolves clean internal domains like tv.loc and home.loc across the LAN, with Caddy handling reverse proxying and automatic HTTPS for each one. Anyone on the network can type a name instead of hunting for an address.

Technitium DNS · Caddy · Docker
