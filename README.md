# idanielm.com — Portfolio Site

Personal portfolio for Daniel B M.

## Concept
Is to allow people who acess the site, a fun way to get to know the creator of the website idaniel.com.

## Structure
- `index.html` — all sections (Hero, About, Skills, Projects, Resume, Contact)
- `assets/css/style.css` — theme, layout, panel styling
- `assets/js/main.js` — GSAP ScrollTrigger animations, nav sync, progress bar
- `assets/images/` — background, project, and profile images
- `assets/pdf/resume.pdf` — downloadable resume (replace placeholder)
