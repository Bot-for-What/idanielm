# idanielm.com — Portfolio Site

Personal portfolio for Daniel B M.

## Concept
A single-page scrolling site with fixed background and each panel slides into view as you scroll. Purpose of the website is to provide people a fun way to get to know the creator of the website [me] at idaniel.com.

## Structure
- `index.html` — all sections (Hero, About, Skills, Projects, Resume, Contact)
- `assets/css/style.css` — theme, layout, panel styling
- `assets/js/main.js` — GSAP ScrollTrigger animations, nav sync, progress bar
- `assets/images/` — background, project, and profile images
- `assets/pdf/resume` — downloadable resumes (2 seprate resumes for International and Indian ATS friendly templates)

## Sections/Panels
- Home - Landing page for idanielm.com
- About Me - Little backstory of my professional journey (current and previous experience)
- Skills - All the skills picked up inorder to solve niche problems
- Projects - A few major achievements specifically highlighting how I used FOSS apps hosted on docker to resolve specific pain points. A few more on the way
- Resume - Self explanatory. International and Indian ATS friendly template provided
- Contact - Only 3 links provided: Email, LinkedIn and Github

## Deployment
- Domain (`idanielm.com`) registered via Porkbun
- Hosted on Hostinger
- Cloudflare for CDN/security layer
